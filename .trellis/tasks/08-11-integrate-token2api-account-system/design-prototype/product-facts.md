# Doge 登录与订阅原型 · Product Facts

> 采集日期：2026-08-15
> 事实源：当前 doge / token2api 工作区代码与既有 OpenSpec；本文件只服务设计原型，不替代正式 behavior spec。

- Doge 是 macOS / Windows 桌面应用，当前已有 light / dark theme。
- 首期自动接入目标引擎为 Codex 与 Claude Code。
- token2api 已有账号、套餐、订单与订阅业务；套餐列表需要登录后读取。
- 当前公开环境无法匿名读取真实套餐，因此原型中的套餐名和价格仅为交互演示数据，不代表正式售价。
- 正式体验目标不向用户展示 API Key、配置文件或凭据存储细节。
- 推荐产品路径：首次登录后选择引擎；后续记住最近使用的引擎，除非用户主动切换。
- 只有“缺少有效权益”进入套餐页；网络错误、服务异常、CLI 未安装必须走各自恢复路径，不能误导用户购买。
- 支付使用外部受信任页面；Doge 保持等待状态并自动确认支付结果，不要求用户点击“我已支付”。
