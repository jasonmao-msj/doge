# Doge 登录 → 引擎 → 订阅原型

这是独立交互原型，不接真实 API，也不会修改本机配置。

打开方式：

1. 双击 `index.html`；或
2. 在仓库根目录运行 `python3 -m http.server 4178`，访问 `http://127.0.0.1:4178/.trellis/tasks/08-11-integrate-token2api-account-system/design-prototype/`。

体验路径：

- 选择 **Codex**：体验“无权益 → 套餐 → 支付 → 自动准备”。支付页出现后，用窗口外的“模拟支付完成”推进。
- 选择 **Claude Code**：体验“已有权益 → 自动准备 → 进入应用”。

原型中的套餐与价格是演示数据，不代表正式售价。
